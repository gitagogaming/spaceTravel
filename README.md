# Void Horizon

## Description
Void Horizon is an exciting and interactive web-based game where you navigate a spaceship to dodge asteroids, collect points, and activate powerful abilities. Your spaceship can move left or right, and your goal is to avoid asteroids, collect green energy nodes for points, and grab **powerups** to gain temporary advantages like shields, speed boosts, and score multipliers.

The game tracks your progress with two labels: one for the distance traveled and one for the score points collected. The game data and graphics are rendered on an HTML5 **`<canvas>`**, providing smoother visuals and a more engaging experience.

## New Features
- **Powerups**: Collect powerups that provide shields, speed boosts, and score multipliers.
- **Canvas Rendering**: Game graphics (spaceship, asteroids, score, and powerups) are drawn using an HTML5 `<canvas>` element for dynamic and smooth animations.
- **Dynamic Difficulty**: Asteroid speed and spawn rates scale as you progress through the game.
- **Modular Code Structure**: The game’s structure has been modularized for easier maintenance and future expansion.
- **Enhanced Visuals**: Use of SVG sprites for high-quality, scalable graphics.

## Technologies Used
- **HTML**: The structure and content of the game, including the `<canvas>` element for rendering game data and visuals.
- **CSS**: Handles the layout and styling of game elements and UI components.
- **Bootstrap**: Used for responsive design and styling components across different devices.
- **JavaScript (JS)**:
  - **Canvas Rendering**: Utilizes the HTML5 `<canvas>` to render and animate game elements like the spaceship, asteroids, and score.
  - **Game Logic**: Handles spaceship movement, collision detection, scoring, and powerup effects.
  - **Arrow Functions**: Provides cleaner and more concise code.
  - **Event Listeners**: Used for user interactions such as keyboard controls and clicking for powerup collection.
  - **Modular Scripting**: Keeps code organized and maintainable with modern JavaScript practices.

## Game Mechanics
- **Spaceship Movement**: Move your spaceship left or right using the arrow keys.
- **Dodge Asteroids**: Avoid collisions with asteroids that appear randomly on the screen.
- **Collect Points**: Click on green energy nodes to collect points and increase your score.
- **Powerups**: Grab powerups to gain shields, speed boosts, and score multipliers.
- **Distance Traveled**: The game tracks the distance your spaceship has traveled.
- **Score Points**: The score increases as you collect energy nodes and powerups.

## How to Play
1. Open the game in a web browser.
2. Use the **Left** and **Right Arrow** keys to move the spaceship.
3. Avoid colliding with asteroids that appear on the screen.
4. Click on **green energy nodes** to collect points.
5. Collect **powerups** for shields, speed boosts, and score multipliers.
6. Keep track of your **distance traveled** and **score** on the displayed labels.
